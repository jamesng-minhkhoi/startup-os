## North Star Metric
- **Metric**: Weekly AI chat sessions per active user
- **Current Value**: <!-- Pre-launch — to be measured -->
- **Target**: 3+ sessions/week (indicates habit formation)
- **Why This Metric**: AI chat is the core differentiator and the primary value loop. Users who chat regularly retain and convert. Scanner usage, health tracking, and memories all feed context back into better AI answers — but the chat is where value is delivered.
