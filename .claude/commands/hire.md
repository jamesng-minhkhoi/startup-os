# Hiring Workflow

Plan and execute a hire: org design, job description, interview process, and offer.

## Steps

1. **Load Context**: Read `context/company.md`. Check for existing org chart in `outputs/hiring/`.

2. **Org Planning** (skill: `org-planning`, `traction-eos`):
   - Review the accountability chart. What seat is missing?
   - Is this the right hire right now? What's the opportunity cost?
   - Define the role using the GWC framework (Get it, Want it, Capacity to do it).

3. **Job Description** (skill: `draft-offer`, `recruiting-pipeline`):
   - Write a compelling job description focused on the mission and impact.
   - Define must-haves vs. nice-to-haves.
   - Include compensation philosophy.

4. **Interview Design** (skill: `interview-prep`):
   - Design a structured interview process (screen → skills → culture → final).
   - Create role-specific interview questions.
   - Define scorecards and evaluation criteria.

5. **Compensation** (skill: `comp-analysis`):
   - Research market rates for this role.
   - Define total compensation (base, equity, benefits).
   - Prepare for negotiation using the negotiation skill.

6. **Output**: Save to `outputs/hiring/{role-name}_{date}.md`.

## Arguments

$ARGUMENTS — The role you're hiring for, or describe the gap on the team.
