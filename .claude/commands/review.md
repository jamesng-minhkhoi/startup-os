# Business Review Workflow (EOS/Traction)

Run a structured business review using the EOS (Entrepreneurial Operating System) framework. Covers vision, people, data, issues, process, and traction.

## Steps

1. **Load Context**: Read all context files. This is a holistic review.

2. **V/TO Review** (skill: `traction-eos`):
   - Review or create the Vision/Traction Organizer:
     - Core Values, Core Focus, 10-Year Target
     - Marketing Strategy (target market, 3 uniques, proven process)
     - 3-Year Picture, 1-Year Plan
     - Quarterly Rocks (3-7 priorities for this quarter)
     - Issues List
   - Score each of the Six Key Components 0-10.

3. **Metrics Scorecard** (skill: `metrics-review`, `scorecard-marketing`):
   - Review the weekly scorecard. Are measurables on track?
   - Apply the marketing scorecard methodology.
   - Flag metrics that have been off-track for 2+ weeks.

4. **Rocks Review** (skill: `roadmap-update`, `sprint-planning`):
   - Are quarterly rocks on track? Score each rock.
   - What's blocked? Apply the IDS process (Identify, Discuss, Solve).
   - Update the roadmap based on current reality.

5. **People Check** (skill: `org-planning`, `performance-review`):
   - Right people, right seats? Review the accountability chart.
   - Any people issues to address?

6. **Financial Health** (skill: `variance-analysis`, `financial-statements`):
   - Revenue vs. plan. Expenses vs. budget.
   - Cash position and runway.

7. **Issues List** (skill: `risk-assessment`):
   - Surface all unresolved issues.
   - Prioritize using IDS: which issues, if solved, would have the biggest impact?
   - Solve the top 3.

8. **Output**: Save to `outputs/strategy/business-review_{date}.md`. Update all relevant context files.

## Arguments

$ARGUMENTS — Specify: quarterly review, monthly check-in, or annual planning. Include any specific concerns.
