# Product Positioning Workshop

Run a full positioning exercise using the Obviously Awesome methodology, enhanced with competitive analysis and market context.

## Steps

1. **Load Context**: Read `context/product.md`, `context/market.md`, `context/customers.md`. This workshop requires knowing the product, market, and customers.

2. **Competitive Landscape** (skill: `competitive-brief`, `competitor-alternatives`):
   - Identify competitive alternatives (direct, indirect, adjacent, substitute).
   - What do customers do today if your product doesn't exist?
   - Build a feature comparison matrix.

3. **Positioning Exercise** (skill: `obviously-awesome`):
   - Walk through the 10 positioning components:
     1. Competitive Alternatives
     2. Unique Attributes
     3. Value Themes
     4. Best-Fit Customers
     5. Market Category
     6. Relevant Trends
     7. Positioning Statement
     8. Sales Narrative
     9. Messaging
     10. Content Strategy
   - Score the positioning 0-10.

4. **Messaging Architecture** (skill: `storybrand-messaging`, `made-to-stick`):
   - Build the StoryBrand narrative (customer is the hero, you are the guide).
   - Apply Made to Stick principles (Simple, Unexpected, Concrete, Credible, Emotional, Stories).
   - Create the headline, subheadline, and elevator pitch.

5. **Output**: Save to `outputs/strategy/positioning_{product-name}_{date}.md`. Update `context/product.md` with positioning decisions.

## Arguments

$ARGUMENTS — The product to position. Include any context about what's not working with current positioning.
