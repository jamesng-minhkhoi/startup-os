# Go-to-Market Strategy Workflow

Build a complete go-to-market strategy: target customer, channels, motions, pricing, and launch plan.

## Steps

1. **Load Context**: Read `context/product.md`, `context/market.md`, `context/customers.md`.

2. **Beachhead Segment** (skill: `beachhead-segment`, `ideal-customer-profile`, `crossing-the-chasm`):
   - Who is the ideal first customer? Be specific (not "SMBs" but "10-50 person SaaS companies with no dedicated ops team").
   - Apply Crossing the Chasm: where are you on the adoption lifecycle?
   - Define the ICP with firmographic, behavioral, and pain-based criteria.

3. **Positioning for GTM** (skill: `obviously-awesome`, `value-prop-statements`):
   - Position specifically for the beachhead segment.
   - Write the value proposition statement.
   - Define the category you're creating or claiming.

4. **GTM Motions** (skill: `gtm-motions`, `gtm-strategy`):
   - Select GTM motion: Product-Led Growth, Sales-Led, Community-Led, or Hybrid.
   - Design the customer acquisition funnel for this motion.
   - Map the buyer journey from awareness to purchase.

5. **Channel Strategy** (skill: `marketing-ideas`, `content-strategy`, `paid-ads`, `cold-email`, `seo-audit`):
   - Select 2-3 primary channels aligned with the GTM motion.
   - For each channel: strategy, first 90-day plan, success metrics.
   - Apply ORB framework (Owned / Rented / Borrowed).

6. **Pricing & Packaging** (skill: `pricing-strategy`, `hundred-million-offers`):
   - Design the pricing model (value metric, tiers, price points).
   - Build the offer stack using Grand Slam Offer methodology.
   - Create Good-Better-Best tiers.

7. **Competitive Battlecards** (skill: `competitive-battlecard`, `sales-enablement`):
   - Create battlecards for top 3 competitors.
   - Define talk tracks for common competitive situations.

8. **Output**: Save to `outputs/strategy/gtm-strategy_{date}.md`. Update `context/market.md` and `context/product.md`.

## Arguments

$ARGUMENTS — Product/feature to take to market, target market hypothesis, and any constraints (budget, timeline, team).
