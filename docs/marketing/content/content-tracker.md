## How to read this
- **Eng.** = likes + comments + saves + shares (whatever the platform gives).
- A post is a **winner** if it beats the channel's running median views AND drove CTA clicks/signups. Winners → make 2 variants (log them, link back via Notes).
- A **dead** format (3 posts, all below median) → stop, switch hook. Note it so we don't repeat.
- Roll the best learning into the next calendar.
