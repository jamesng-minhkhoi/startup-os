# Template — Instagram Carousel (VN)

Educational, save-worthy carousels. Drives bio-link traffic to the Food Checker.

## Prompt (copy this into Claude)

```
Read context/product.md and context/customers.md.

Write an Instagram carousel for Petio (Vietnamese pet-care audience).

INPUTS:
- Topic: <e.g. chó ăn được gì A–Z / 3 thứ cần nhìn trên nhãn / dấu hiệu dị ứng>
- Slides: <6 | 8 | 10>

REQUIREMENTS:
- Native casual Vietnamese.
- Slide 1 = scroll-stopping cover (big claim or question). Last slide = soft CTA to bio link (Food Checker).
- One idea per slide, <20 words each, so Ngoc can design clean.
- Give: cover text, each slide's text, the caption (with 1 question to drive saves/comments), 8 hashtags.
- Save-worthy: someone should bookmark it as a reference.
- No medical/diagnosis claims.
```

## Checklist
- [ ] Cover stops the scroll
- [ ] One idea per slide, short enough to design
- [ ] Last slide CTA → bio (Food Checker)
- [ ] Caption ends with a question
- [ ] Logged in content-tracker
