# Template — TikTok / Reels Scan Demo

The core Petio video format: scan a popular pet food on camera, show the result. "Boss đang ăn gì?" (VN) / "Is This Safe?" (US). No voiceover needed — the result speaks.

## Prompt (copy this into Claude)

```
Read context/product.md, context/customers.md, and context/market.md.

Write a TikTok/Reels script for Petio's scan-demo format.

INPUTS:
- Market: <VN | US>
- Brand to scan: <e.g. Pedigree / Milk-Bone>
- Pet/breed angle: <e.g. Golden Retriever / mèo dị ứng cá / generic>
- Hook angle: <scan-result | compare-two-brands | myth-bust | allergy-check>

REQUIREMENTS:
- Output: (1) on-screen text hook for first 2 seconds, (2) 15–30s shot-by-shot beat sheet,
  (3) caption, (4) 5 hashtags, (5) suggested sound type.
- If VN: write everything in native, casual Vietnamese (dùng "boss", "sen", giọng thân thiện). NOT translated.
- First 2 seconds must stop the scroll — lead with surprise or a question.
- Show the scan happening on camera; reveal the result, especially anything flagged.
- NO voiceover script needed (text-on-screen only), but give an optional 1-line spoken hook.
- NO medical/diagnosis claims. Frame as "ingredient check / kiểm tra thành phần".
- CTA: VN → "link kiểm tra free ở bio" (Food Checker). US → soft "Petio in App Store" only at end, low-key.
- Give me 2 hook variants so I can A/B test.
```

## Proven hooks (prime the model with these)
**VN**: "Mình quét thử [brand] — loại bán chạy nhất Shopee thú cưng 👀" · "Boss nhà bạn ăn [A] hay [B]? Mình quét cả 2" · "3 món người hay cho chó ăn mà thật ra nguy hiểm 🚫"
**US**: "I scanned the #1 selling dog treat in America." · "My dog's allergic to chicken — here's how I check every label." · "Is [Blue Buffalo] actually safe? I scanned it."

## Checklist before posting
- [ ] Hook lands in first 2 seconds
- [ ] Real scan shown on camera (not a mockup)
- [ ] Native language, casual tone
- [ ] No diagnosis claim
- [ ] Correct CTA for current launch phase
- [ ] Logged in content-tracker with both hook variants if A/B testing
