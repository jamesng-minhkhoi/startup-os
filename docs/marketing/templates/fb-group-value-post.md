# Template — Facebook Group Value Post (VN, trust-first)

For VN pet/allergy Facebook groups. During the trust-building window: **pure value, no app push**. Earn the right to mention Petio later.

## Prompt (copy this into Claude)

```
Read context/product.md and context/customers.md.

Write a helpful Facebook post for a Vietnamese pet-owner group.

INPUTS:
- Topic: <e.g. món chó cấm ăn / đọc nhãn thức ăn / dấu hiệu dị ứng / so sánh brand>
- Group vibe: <general HCMC pet group | breed-specific | allergy/health group>
- Trust level: <cold (no app mention) | warm (soft tool mention allowed)>

REQUIREMENTS:
- Native, warm, casual Vietnamese — như một người nuôi thú thật sự chia sẻ, không phải brand.
- Genuinely useful on its own — someone should want to save it even if Petio didn't exist.
- Structure: hook line → 3–7 concrete points (scannable, emoji light) → 1 friendly closing question to drive comments.
- If trust = cold: ZERO app mention. If warm: ONE soft line at the end ("mình hay check nhanh bằng tool free này: [Food Checker link]").
- NO medical/diagnosis claims. NO salesy tone.
- Length: 120–250 words.
- Give a short version (for comments) and a full version (for a standalone post).
```

## Value themes that work (VN)
Món cấm theo loài · cách đọc nhãn · dấu hiệu dị ứng thức ăn · so sánh brand phổ biến · dinh dưỡng theo giống · lỗi người nuôi lần đầu hay mắc · scan result của 1 brand cộng đồng hay hỏi.

## Checklist
- [ ] Useful even without Petio
- [ ] Sounds like a real owner, not a brand
- [ ] Ends with a question (drives comments → algorithm)
- [ ] App mention matches trust level (cold = none)
- [ ] No diagnosis claims
