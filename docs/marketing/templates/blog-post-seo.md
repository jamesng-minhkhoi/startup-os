# Template — SEO Blog Post (VN + US)

Long-form articles that rank for pet-food-safety queries and drive organic Food Checker / app traffic. The long-term acquisition engine.

## Prompt (copy this into Claude)

```
Read context/product.md, context/customers.md, and context/market.md.

Write an SEO blog post for petiogo.com.

INPUTS:
- Market/language: <VN (native Vietnamese) | US (English)>
- Target keyword: <e.g. "chó ăn được gì" / "dog food scanner" / "can my dog eat X">
- Search intent: <informational | comparison | how-to>

REQUIREMENTS:
- 1,500–2,500 words. Native language (VN = written natively, NOT translated).
- Lead with a direct answer (QuickAnswer box) for featured-snippet capture.
- H2/H3 structure mapping to related queries. Scannable: tables, lists, bolded key facts.
- Cite real sources where claims need backing. Use real, popular brands for the market.
- Natural scanner CTA mid-article + end ("kiểm tra free tại Food Checker" / App Store).
- Include an FAQ section (feeds FAQPage JSON-LD).
- Suggest: title tag (<60 chars), meta description (<155 chars), slug, 3 internal links to existing posts/tools.
- NO medical/diagnosis claims. Reassuring, practical tone.
```
