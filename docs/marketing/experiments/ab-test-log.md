## Test entries

### AB-001 — Threads VN: which PAIN POINT wins (not which hook)
- **Status**: designing → ready to run
- **Market / surface**: VN · Threads (pet niche)
- **Hypothesis**: We believe testing *different pain points* (not hook wording) will reveal one wedge that out-pulls the rest on engagement, because the audience responds to identity/pain topics, not product features. (Source: Manus research, `../../outputs/marketing/threads-research_manus_2026-06-21.md`.)
- **One variable**: the pain-point angle per post (food safety vs kén ăn vs lười uống nước vs info-overload vs founder-pivot vs first-time-parent vs health-tracking vs hot-take …)
- **Method**: post 10, one per angle, ALL in Threads VN pet voice (`templates/threads-vn-pet-style-guide.md`, 50–120 chữ, product as a tiny detail)
- **Primary metric**: Reply/View % (engagement) · secondary: Like/View %, profile visits
- **Sample / duration**: 10 posts over ~2 weeks; need enough views/post to read signal — if volume too low, extend
- **Result**: <fill>
- **Decision**: scale the winning angle into the next Threads calendar; retire dead angles
- **Fed back into**: <which calendar / template got updated>

> Note: the early Manus sample copy was rejected for being too salesy — this test is about *angle*, executed in the correct voice.
