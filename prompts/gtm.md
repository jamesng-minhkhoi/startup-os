# Go-to-Market Strategy Workflow

Paste this into Claude Desktop to build a GTM strategy.

---

**Prompt:**

> Build a go-to-market strategy for: [PRODUCT/FEATURE, TARGET MARKET HYPOTHESIS, CONSTRAINTS]
>
> Follow these steps in order:
>
> 1. Read `context/product.md`, `context/market.md`, `context/customers.md`
> 2. Use `beachhead-segment`, `ideal-customer-profile`, `crossing-the-chasm` — define specific ICP with firmographic, behavioral, and pain-based criteria. Where on the adoption lifecycle?
> 3. Use `obviously-awesome` and `value-prop-statements` — position for the beachhead, write the value proposition, define the category
> 4. Use `gtm-motions` and `gtm-strategy` — select motion (PLG, Sales-Led, Community-Led, Hybrid), design acquisition funnel, map buyer journey
> 5. Use `marketing-ideas`, `content-strategy`, `paid-ads`, `seo-audit` — select 2-3 primary channels, first 90-day plan per channel, apply ORB framework
> 6. Use `pricing-strategy` and `hundred-million-offers` — design pricing model, build the offer stack, Good-Better-Best tiers
> 7. Use `competitive-battlecard` — battlecards for top 3 competitors with talk tracks
> 8. Save to `outputs/strategy/gtm-strategy_2026-04-06.md` and update `context/market.md` and `context/product.md`
