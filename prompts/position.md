# Positioning Workshop Workflow

Paste this into Claude Desktop to run a positioning exercise.

---

**Prompt:**

> Run a positioning workshop for Petio. [INCLUDE ANY CONTEXT ABOUT WHAT'S NOT WORKING WITH CURRENT POSITIONING]
>
> Follow these steps in order:
>
> 1. Read `context/product.md`, `context/market.md`, `context/customers.md`
> 2. Use `competitive-brief` and `competitor-alternatives` — identify competitive alternatives (direct, indirect, adjacent, substitute), what do customers do today without us, build feature comparison matrix
> 3. Use `obviously-awesome` — walk through all 10 positioning components (Competitive Alternatives, Unique Attributes, Value Themes, Best-Fit Customers, Market Category, Relevant Trends, Positioning Statement, Sales Narrative, Messaging, Content Strategy). Score 0-10
> 4. Use `storybrand-messaging` — build the StoryBrand narrative (customer is the hero, we are the guide). Use `made-to-stick` to apply SUCCESs principles. Create headline, subheadline, and elevator pitch
> 5. Save to `outputs/strategy/positioning_petio_2026-04-06.md`
> 6. Update `context/product.md` with positioning decisions
