# Business Review Workflow (EOS/Traction)

Paste this into Claude Desktop to run a structured business review.

---

**Prompt:**

> Run a [quarterly review / monthly check-in / annual planning] for Petio. [ANY SPECIFIC CONCERNS]
>
> Follow these steps in order:
>
> 1. Read all context files for a holistic view
> 2. Use `traction-eos` — review or create the V/TO (Vision/Traction Organizer): Core Values, Core Focus, 10-Year Target, Marketing Strategy, 3-Year Picture, 1-Year Plan, Quarterly Rocks, Issues List. Score each of the Six Key Components 0-10
> 3. Use `metrics-review` — review weekly scorecard, flag metrics off-track 2+ weeks
> 4. Use `roadmap-update` and `sprint-planning` — are quarterly rocks on track? Score each. Apply IDS (Identify, Discuss, Solve) for blockers
> 5. Use `org-planning` — right people, right seats? Review accountability chart
> 6. Use `variance-analysis` and `financial-statements` — revenue vs plan, expenses vs budget, cash and runway
> 7. Use `risk-assessment` — surface unresolved issues, prioritize with IDS, solve the top 3
> 8. Save to `outputs/strategy/business-review_2026-04-06.md` and update all relevant context files
