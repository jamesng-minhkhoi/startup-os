# Hiring Workflow

Paste this into Claude Desktop to plan and execute a hire.

---

**Prompt:**

> Plan a hire for: [ROLE OR DESCRIBE THE GAP ON THE TEAM]
>
> Follow these steps in order:
>
> 1. Read `context/company.md`. Check `outputs/hiring/` for existing org chart
> 2. Use `org-planning` and `traction-eos` — review accountability chart, is this the right hire right now, define role using GWC (Get it, Want it, Capacity)
> 3. Use `draft-offer` and `recruiting-pipeline` — write job description focused on mission and impact, define must-haves vs nice-to-haves, include comp philosophy
> 4. Use `interview-prep` — design structured interview process (screen > skills > culture > final), create role-specific questions and scorecards
> 5. Use `comp-analysis` — research market rates, define total comp (base, equity, benefits), prepare for negotiation
> 6. Save to `outputs/hiring/[role-name]_2026-04-06.md`
