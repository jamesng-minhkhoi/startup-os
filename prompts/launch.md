# Launch Planning Workflow

Paste this into Claude Desktop to plan a product launch.

---

**Prompt:**

> Plan a launch for: [WHAT YOU'RE LAUNCHING, WHEN, BUDGET, CONSTRAINTS]
>
> Follow these steps in order:
>
> 1. Read `context/product.md` and `context/market.md`. Check `outputs/strategy/` for existing positioning
> 2. Use `launch-strategy` — determine launch type, apply the Five-Phase model (Internal > Alpha > Beta > Early Access > Full Launch), map channels using ORB framework (Owned/Rented/Borrowed), build the launch checklist
> 3. Use `campaign-plan` and `marketing-ideas` — define goals, audience, timeline, select 3-5 marketing ideas filtered by stage and budget, plan the content calendar
> 4. Use `copywriting` — write landing page copy (headline, subheadline, CTA, social proof, objections). Use `email-sequence` for announcement sequence. Use `social-content` for launch day posts
> 5. Use `signup-flow-cro` and `onboarding-cro` — audit signup flow friction and plan the new-user experience
> 6. Use `runbook` and `risk-assessment` — create launch day runbook (who does what, when) and identify risks with mitigations
> 7. Save to `outputs/marketing/launch-plan_2026-04-06.md`. Save copy assets separately
